# Source provenance

This service core is a clean product-neutral extraction of the provider boundary already documented in the existing ICA and identity-application repositories.

No existing ICA server, route, deployment manifest, tenant configuration, key material or persistence implementation was copied. The source repositories were not modified.

Future adapters may be migrated file by file only after their endpoint, authentication, storage, ledger and key-custody contracts have been audited against this service boundary.
